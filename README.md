# 📖 About

This repository is my personal journal documenting my journey learning Python backend development.

Instead of simply taking courses, I logged **each day of study**, took detailed notes, completed practical assignments, and gradually built increasingly complex backend applications.

Following this learning plan, I covered topics ranging from databases to deployment and asynchronous architecture, keeping all my work in a single repository.

Sometimes I would complete a section of the program in just five days, while at other times I spent over **10+ hours a day studying**.

The reason this covers only roadmap days 111 through 210 is that, prior to day 110, I took my notes in .docx files.
