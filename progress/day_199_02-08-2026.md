# День 199 (02.08.2026): Профилирование приложения с cProfile и визуализация
## Теория:
* Что такое профилирование (Macro-benchmarking): как найти "бутылочное горлышко" (bottleneck) в большом проекте, не замеряя каждую функцию вручную.
* Модуль cProfile: встроенный C-профайлер Python. Разбор его метрик: ncalls (количество вызовов), tottime (время внутри функции без учета вложенных), cumtime (общее время с учетом вложенных вызовов).
* Построчное профилирование: зачем нужна сторонняя библиотека line_profiler, если cProfile показывает только время работы функции целиком, но не говорит, какая именно строчка внутри неё тормозит.
* Визуализация данных профилирования: как читать "пламенные графы" (Flame Graphs) и графы вызовов с помощью утилит вроде SnakeViz.
## Практика:
* Напиши намеренно медленный скрипт (например, функция, которая делает вложенные циклы, читает файл с диска и производит бесполезные вычисления).
* Запусти скрипт через профайлер в терминале: python -m cProfile -s cumtime my_script.py. Изучи текстовый вывод и найди самую медленную функцию.
* Сохрани результаты профилирования в файл: python -m cProfile -o profile_data.prof my_script.py.
* Установи snakeviz (pip install snakeviz) и открой сохраненный файл в браузере: snakeviz profile_data.prof. Изучи интерактивный график вызовов.
