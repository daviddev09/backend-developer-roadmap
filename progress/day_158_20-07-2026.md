## Конспект изученных материалов
### 1. Как обновлять PR
* **Pull Request** привязан не к конкретным коммитам а к самой ветке. Пока PR открыть, GitHub непрерывно слушает твою удаленную ветку. Если в ней появляются новые коммиты, они автоматически подтягиваются в интерфейс PR
### 2. Локальный Rebase против удаленной ветки
* Rebase переписывает историю и создает новые хэши коммитов. После rebase на Github лежат коммиты: С0, С1, С2, С3. А у тебя на компьютере: Сх. Когда делаешь обычный push, Git сравнивает истории. Он видит, что удаленная ветка и локальная ветка полностью разошлись. Git решает что ты случайно удалил чью-то чужую работу на сервере и выдает ошибку, а потом предлагает сделать: **git pull**. А если сделать *git pull* то случиться:
    * Git скачает старые коммиты с GitHub и сольет их с твоим новым коммитом. В истории появляется merge-коммит и дубликаты одних и тех же изменений. Вся работа по rebase пойдет насмарку
### 3. Force Push: опасность и необходимость
* Чтобы решить проблему из предыдущего пункта, тебе нужно приказать GitHub: "Я знаю, что истории не совпадают. Забудь то, что у тебя есть, и перезапиши свою историю моей локальной версией".
* **Опасность git push --force:** Эта команда берет локальную ветку и вслепую стирает всё, что находится в удаленной ветке на сервере, заменяя локальными данными. Если сделать это в публичной ветке main, это сотрет код коллег, которые они успели туда запушить.
* **Спасительная альтернатива:** Обычный --force слеп и опасен, и поэтому разработчики Git придумали "предохранитель" - команду *force-with-leace* (переводится как: принудительно, но с проверкой аренды). Как она работает:
    * Перед тем как перезаписать историю на сервере, Git проверяет: "А не добавил ли кто-нибудь другой новые коммиты в эту ветку на GitHub с момента моего последнего взаимодействия с ней?"
    * Если никто не трогал удаленную ветку - команда отработает обычный *force push* и перезапишет историю
    * Если кто-то успел добавить туда коммит, о котором твой локальный Git не знает - операция будет заблокирована. Это спасет работу коллеги от случайного стирания.
