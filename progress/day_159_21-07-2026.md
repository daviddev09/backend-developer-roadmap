## Конспект изученных материалов
### Главные правила работы в терминале Linux
* **1. Приглашение ввода:** Когда система готова к работе, ты видишь строку вроде: *user@ubuntu-server:~$
    * *user* имя пользователя
    * *ubuntu-server* имя виртуальной машины
    * *~* значок тильды показывает что ты находишься в своей домашней папке.
    * *$* означает, что ты вошел под обычным пользователем (у админа root здесь символ #).
* **2. Регистр имеет значение:** В отличие от Windows, файлы *File.txt*, *file.txt* и *FILE.txt* это три абсолютно разных файла
* **3. Главная клавиша помощник - Tab:** Начни писать имя папки или команды и нажми Tab. Linux сам допишет название! Нажмешь Tab дважды - он покажет все доступные варианты.
### 1. Иерархия файловой системы Linux
* В Linux в отличие от Windows где есть разные диски (**C**, **D**), вся система представляет собой единое перевернутое дерево файлов.
    * **Корневой каталог (/)** это самый верх всей системы (корень). Абсолютно все папки, файлы, флешки и жесткие диски находятся внутри корневого каталога **/**.
    * **Домашняя директория (~ или /home/username)** твоя личная папка. Для пользователя **user** путь к ней будет **/home/user**. Символ **~** - это просто короткий псевдоним для твоей домашней папки.
* **Абсолютные и относительный пути:**
    * **Абсолютный путь** указывает точное местоположение файла, начиная от самого корня /. Он всегда начинает со слэша **/**.
        * **Пример:** /var/log/syslog** (открой корень /, найди папку var, в ней log, а там файл syslog).
    * **Относительный путь** указывает путь относительно той папки, в которой находишься прямо сейчас.
        * **.** - текущая папка.
        * **..** - родительская папка.
        * **Пример:** Если ты уже находишься в **/var**, то относительный путь к лонам будет просто **log/syslog**.
### 2. Навигация по системе: **pwd**, **ls**, **cd**
1) **pwd (Print Working Directory) - "Где Я?"** Печатает абсолютный путь к текущей папке, в которой ты находишься
2) **ls (List) - "Что здесь лежит?"** Показывает список файлов и папок в текущей директории. Важные флаги для ls:
    * **ls -l** вывод в виде подробного списка
    * **ls -a** показать все файлы, включая скрытые
    * **ls -lh** флаг -h (human readable) показывает размер файлов в понятном виде (КБ, МБ, ГБ вместо байт)
    * **Флаги можно комбинировать, например:** *user@ubuntu-server:~$ ls -la -lh*
3) **cd (Change Directory)** - Перемещение. Позволяет переходить из одной папки в другую. Например:
    * *cd Documents* Перейти в конкретную папку (относительный путь)
    * *cd /var/log* Перейти по абсолютному пути
    * *cd ..* Поднятся на один уровень верх
    * *cd*, *cd ~* Вернутся в домашнюю директорию
    * *cd -* Вернутся в предыдущую папку, где ты был только что
### 3. Управление файлами и папками: **touch**, **mkdir**
1) **touch** - создание пустого файла. Команда touch создает пустой файл с указанным именем, например:
    * *user@ubuntu-server:~$ touch david.txt*
2) **mkdir (Make directory)** - создание папок. Создает новую директорию:
    * *user@ubuntu-server:~$ mkdir daviddevs_project
    * Если нужно создать вложенную структуру папок, обычная команда выдаст ошибку, так как родительских папок ещё нет. Используй флаг **-p**: *user@ubuntu-server~$ mkdir -p projects/python/app*
### 4. Копирование, перемещение и удаление: **cp**, **mv**, **rm**
1) **cp (Copy)** - Копирование.
    * *cp notes.txt notes_backup.txt* Копирование файла: cp <что копируем> <куда копируем>
    * *cp -r my_project my_project_backup* Копирование папки со всем её содержимым. Флаг **-r** (recursive) обязателен
2) **mv (Move)** - Перемещение и переименование. В Linux одна и та же команда **mv**, используется и для перемещения файлов, и для их переименования.
    * *mv notes.txt old_notes.txt* Переименование (если путь назначения - это новое имя в той же папке)
    * *mv notes.txt my_project/* Перемещение (если указываем другую папку)
3) **rm (Remove)** - Удаление. В консоли Linux нет корзины! Удаленные файлы стираются навсегда.
    * *rm old_notes.txt* Удаление одного файла
    * *rm -r my_project_backup* Удаление и всего её содержимого - флаг **-r**
    * Флаг **-f**(force) отключает запросы на подтверждение. Команда *rm -rf <папка>* безвозвратно удаляет всё содержимое без пердупреждений
### 5. Чтение содержимого файлов терминале
1) **cat** - быстро выдать весь файл. выводит всё содержимое файла прямо в консоль. Удобно для маленьких файлов.
    * *user@ubuntu-server:~$ cat /etc/issue*
2) **less** - постраничный просмотр длинных файлов. Если файл огромный (например, логи), **cat** заполнит весь экран текстом. Команда **less** открывает файл во встроенном просмотрщике.
    * *user@ubuntu-server:~$ less /var/log/syslog
    * **PageDown/PageUp или стрелочки на клавиатуре:** Листать вниз/вверх
    * **Нажать /, ввести слово и нажать Enter:** Поиск по тексту
    * **нажать q** выход из режима просмотра
3) **tail** - чтение конца файла и логов в реальном времени
    * *tail /var/log/syslog* Показать последние 10 строк файла
    * *tail -n 20 /var/log/syslog* Показать последние 20 строк
    * *tail -f /var/log/syslog* Режим отслеживания в реальном времени (-f): Консоль замирает, и на лету выводит новые строки, которые записываются в файл. Чтобы выйти из этого режима, нужно нажать комбинацию клавиш: **Ctrl + C**
